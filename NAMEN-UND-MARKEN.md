# Namen und Zeichen

Der Code dieses Repositorys steht unter der EUPL 1.2. **Die Namen und Logos
stehen nicht darunter.** Die Lizenz erlaubt Ihnen, den Code zu benutzen, zu
ändern und weiterzugeben - sie erlaubt nicht, Ihre Fassung unter unseren Namen
anzubieten (EUPL Art. 5: Die Lizenz gewährt keine Rechte an Namen, Marken oder
Zeichen).

## Geschützte Namen

- Tastenflow
- Lernwerkstatt
- Sensorik

dazu die Logos und Symbole (`public/tastenflow-logo*`, `src/components/TastenflowLogo.tsx`,
`src/components/Logo.tsx`).

## Was Sie dürfen

- Den Code für jeden Zweck benutzen, auch in der Schule, auch auf einem
  eigenen Server.
- Sagen, dass Ihre Fassung auf Tastenflow **beruht**, zum Beispiel „beruht auf Tastenflow".
- Die unveränderte Fassung unter ihrem Namen weitergeben.

## Was Sie bitte nicht tun

- Eine veränderte Fassung unter einem dieser Namen oder mit einem dieser Logos
  anbieten.
- Den Eindruck erwecken, Ihre Fassung komme von uns oder sei von uns geprüft.

Wenn Sie eine veränderte Fassung veröffentlichen: geben Sie ihr bitte einen
eigenen Namen und tauschen Sie die Logos aus.

Fragen dazu: über die Fehlermeldungen (Issues) dieses Repositorys.
